# 🛒 AI-Driven Retail Demand Pulse & Automatic Replenishment System

> **Final Year Project** — Eldoret, Kenya  
> A realistic synthetic dataset + full ML pipeline for demand forecasting, spoilage prediction, anomaly detection, and automatic stock replenishment for Kenyan SME retail shops.

## Quick Start

### 1. Install

```bash
cd retail_demand_pulse
pip install -e .
```

### 2. Run the full pipeline

```bash
python -m retail_demand_pulse.pipeline
```

### 3. Run individual stages

```bash
# Generate the dataset only
python -m retail_demand_pulse.dataset

# Clean → feature-engineer (skip EDA for speed)
python -m retail_demand_pulse.pipeline clean features

# Train all models
python -m retail_demand_pulse.pipeline train_demand train_spoilage anomaly_detection replenishment
```

## Dataset Details

| Property | Value |
|---|---|
| Date range | 2024-01-01 → 2025-12-31 |
| Products | 20 (10 perishable, 10 non-perishable) |
| Categories | Dairy, Bakery, Vegetables, Fruits, Staples, Beverages, Condiments, Cooking, Personal Care, Household |
| Rows | ~14,600 (20 products × 730 days) |
| Columns (raw) | 21 |
| Columns (processed) | ~45 |

### Key Patterns Embedded

- **Weekend & public holiday boost** — Kenyan holidays: Madaraka Day, Jamhuri Day, Christmas, etc.
- **Long-rains / short-rains seasonality** — March–May & October–November, calibrated to Eldoret climate
- **Market day effect** — every Tuesday & Friday (Eldoret market days)
- **Temperature → beverage demand** positive correlation
- **Heavy rain → perishable demand** negative correlation
- **End-of-month demand surge** — salary effect
- **School term opening boosts** — January, May, September

## ML Models

### A. Demand Forecasting
| Model | Features | Evaluation |
|---|---|---|
| **XGBoost** | Lag features, rolling stats, weather, calendar | MAE, RMSE, MAPE |
| **LSTM** | Multivariate time-series (14-day lookback) | MAE, RMSE, MAPE |

### B. Spoilage Risk Prediction
- **Regression** — GradientBoostingRegressor → score ∈ [0, 1]
- **Classification** — GradientBoostingClassifier → HIGH / LOW risk (threshold 0.35)

### C. Anomaly Detection
- **Isolation Forest** — 3 % contamination, multivariate feature space

### D. Replenishment Engine
- Rule-based using: forecasted demand × safety stock × lead time → reorder quantity
